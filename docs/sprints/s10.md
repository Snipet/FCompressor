## Lead revisions at the S10 base

1. **Standing rules** (`CLAUDE.md`; `docs/sprints/s1.md` Lead revisions 1–5): full `FCMP_WARNING_FLAGS` with `-Werror`;
   `FCDSP_NONBLOCKING` on out-of-line definitions of annotated declarations; probe exit-code rules; ≤ 2 build
   directories, `-j6`, delete them after recording results. **No mid-task questions**: make minimal design-mandated
   out-of-OWNS edits yourself and flag them in the handoff. Probe-own flags go after a lone `--`. Agents never push.
2. **S10 interface revision (X10, merged in this base; 01 §5.1–5.3, §7, §8.2 "S10 interface revision"):**
   `FbAffine{A, B, base}` — r = base + A + B·r̂(x − r); every `G::solveFb` returns r − base (base 0 = the old solve).
   Optional hooks detected in `Stage.h`: `S2::combineStatic(c, r1, xDb, l)` (→ `ModeEntry::staticS2`, drawn by
   `analysis::staticGain` when `CurveOpts::stage2`), `G::rhatFb(c, y, l)`, `B::commitFb(c, s, r, rhat)` (exact commit),
   `B::fbFalls(s)`. FET 76's FB release now carries sub-ulp steps.
3. **M4 (Mu 67).** `FeedbackZdf<ProgressiveKnee>` already honours `base`; any closed-form law must honour `base` too or
   wrap in `FeedbackZdf`. `TcSelector` gets the carry by calling `SmoothBranching::solveFb/commitFb` per path; if it
   builds its own max-of-roots maps (`MultiStage3` included) it must copy `SmoothBranching::solveFb`'s pattern (map
   `{lo − k(r + lo), k, base = r}`, then split the step into r and lo). Each carried sample costs one extra solve —
   watch the ns budget (run `fcmp_bench --mode mu-67` only when no other agent is building, and report it).
   ADR-63: published (closed-loop) times, converted in `physical()`.
4. **M5 (Diode 609).** Give `SharedElementMax` a `combineStatic` so `ModeEntry::staticS2` fills itself and the transfer
   curve draws stage 2. Probes that call `ModeEntry::staticGr` directly (`dsp.static`, `dsp.hostile`, `dsp.srsweep`)
   see the computer alone — with stage 2 on they must compose `staticS2` (flagged out-of-OWNS probe edits are expected).
   `DualRelease` (A1/A2) gets the exact r̂ commit automatically, also through `AutoSwitch`; its own maps are still solved
   absolute, so a multi-second A2 release in FB can still stall sub-ulp — document the residual. ADR-64: shared tags
   routed through `m[]`; `s2thr` OFF = 24, never `kTagOff`.
5. **U7 (GPU editor).** FunkGui v0.7.0 `EditorHost` (see its CHANGELOG): surface lifecycle, fallback, backing scale,
   `FramePump`, `CaptureConfig` from the `FCMP_` env prefix, `A11yBridge`, runtime ObjC names. The HardwareReverb port
   found three small `EditorHost` gaps worth knowing: the theme index is not exposed to the Panel (a theme-cell click
   applies one frame later), `fileDragEnter/Exit` are not forwarded, and a Panel has no owner component for
   `PopupMenu`/`FileChooser` (HR sets it through `setOwner()`). Live tests need the window server (the Mac is awake):
   use the `lockf /tmp/fcmp-gui.lock` guard. You are the only GUI agent this sprint.
