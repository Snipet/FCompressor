   stubs; U5 and U6 fill them in without changing their declarations (additive only).

   - `PresetHooks{isPresetParameter, beginApply, applyBefore, onApplied, captureExtra, findFactory, initialPreset,
     mixParameter}`, `PresetManager(apvts, hooks)`, `PresetStore(const ProductConfig&)`, `PresetFile::*(config, …)`.
     ProductConfig is `{"FCompressor", ".fcmppreset", "FCompressorPreset", "FCMP_PRESETS_DB"}`.

   - Use `PresetManager::isModified()` as shipped (HR's rule: half an interval, in plain units), not the card's
     1e-4; G8 found HR's own code rejects 1e-4. Record it if a stepped, hybrid or locked parameter (snap-on-read)
     needs anything else.
   - `mixParameter` stays empty: FCompressor has no load-time mix lock, and Brickwall's mix is Mode-locked by the
     resolver.
   - Import/export uses `funkgui::presets::PresetFile` directly; this is the snapshot case, so no adapter.
   - The factory bank covers all 8 Modes (Init at index 0).
