1. **Standing rules** (`CLAUDE.md`; `docs/sprints/s1.md` Lead revisions 1–5): full `FCMP_WARNING_FLAGS` with `-Werror`;
   `FCDSP_NONBLOCKING` on out-of-line definitions of annotated declarations; probe exit-code rules; ≤ 2 build
   directories, `-j6`, delete them after recording results. **No mid-task questions**: make minimal design-mandated
   out-of-OWNS edits yourself and flag them in the handoff. Probe-own flags go after a lone `--`. Agents never push.
2. **State since S12** (`docs/sprints/s12.md` Outcome). The panel is complete: ZOOM (UF1b), the Mode browser (U5),
   the preset strip and browser with save-over (U6, P3c), and the HISTORY · VU switch (UF2). Presets run on FunkGui
   v0.8.0 FunkPresets (P3, P3b). R1 (`Scripts/release.sh`) is already merged, pulled forward in S12, so S13 runs H1a
   and H1b only. The S12 milestone gates: asan, tsan, tsan-agent and rtsan green; gui-live 5/5; universal compile
   green; bench (see revision 5).
3. **H1a gets a first deliverable before the audit: ADR-73, the high-contrast PAPER.**
   - The Panel maps `themeIndex()` 1 to FCompressor's own palette (a new `Source/editor/ProductTheme.h`, or inside
     `Panel.cpp`) and passes it to every sub-view. FunkGui's `Theme::paper()` is untouched, and so is GRAPHITE.
   - Keep the ground `EDEBE6`. Meet ADR-73's WCAG targets, keep the ladder strictly ordered, and re-tune `textGamma`
     by eye on the PNGs.
   - New probe `ui.contrast` (global, spec-only): each PAPER token's ratio against its target, the ordering, and
     GRAPHITE unchanged.
   - PNGs of all 5 views in PAPER, before and after, to `scratchpad/h1a-png/`. The user asked for this directly, so the
     result must be clearly more legible, not a marginal tweak.
4. **H1a audit items** carried from S9–S12:
   - TransferPlot's "0 DB <LAW>" label overflows its plot (≈ x 785 at the 72 dB scale).
   - HistoryPlot should use `HistoryStore::columnWindows`.
   - Move the Panel crossfade onto `funkgui::ScreenFader`.
   - Put the Mode and preset browsers in the Tab order (U6); today only VoiceOver reaches RENAME / IMPORT / EXPORT.
   - U5: two focus rings when the Mode browser is opened from the keyboard, and items covered by an open overlay still
     listed as visible in a11y.
   - UF1a: a stale gap that starts and ends while a plot is hidden is not drawn.
   - Every slot is a Tab stop, including locked, derived and n/a ones; handled keys return `true`.
   - The `ui.{geometry,a11y,input}` rows must be stable for FZ5 adoption: rerun twice, identical.
   - A VoiceOver checklist for the lead.
   - Use `fcmp::product::kPresetExtension` (the lead adds it to `FcmpProduct.h` at this base) instead of the literal
     `.fcmppreset` in PresetBrowser.
5. **H1b findings list** (its OWNS is exactly these files and their probes; see the manifest):
   a. **Processor race** (S8): `notice_`/`ui_` are read by the editor while a host calls `setStateInformation` off the
      message thread. Make the handoff lock-free and correct, and prove it with a tsan-agent row.
   b. **AU optional side-chain bus** (S7): auval prints "non-main buses failed". Make `isBusesLayoutSupported` /
      the AU channel layouts clean, so auval -strict prints no bus warning. Keep the VST3 layouts unchanged.
   c. **CPU budgets.** Use the quiet-machine bench at this base (revision 6):
      - set `ctBudgetNsPerSample` for Bus 25 and Brickwall from measurement;
      - reduce Opto 2A's and Mu 67's attached (telemetry and internals) cost where it is avoidable, or document why
        not;
      - decide the HQ budget rule, meaning either a per-quality budget or a documented multiplier in docs/modes and
        the bench report. The bench must pass its own budget rows.
   d. **Telemetry attach cost** in EngineHost (UiFrame and HistoryRing gated by the attach count): measure it and cut
      whatever is avoidable.
   e. `Source/plugin/factory/FactoryBank.cpp` uses `fcmp::product::kPresetExtension` instead of the literal.
   f. **Optional, only if a–e are done:** a Brickwall post-downsample ceiling guard at STD, so the band-limited-square
      stress also stays ≤ +1.0 dB TP. It must not move any other Mode's goldens, and Brickwall's `dsp.*` drift needs a
      one-line reason per group.
6. **Bench at this base** (lead, quiet machine, `ctest --preset lead -L bench` alone): see the S12 Outcome for the
   numbers. H1b runs its own A/B benches in its worktree. Never run `fcmp_bench` while the other card builds; take
   `lockf -k -t 1800 /tmp/fcmp-bench.lock` around every bench run.
7. **Expected candidates:** `ui.{geometry,a11y,input}` × 8 only; the lead blesses them at FZ5 after this sprint.
