## Lead revisions at the S3 base

1. **Standing rules** (`docs/sprints/s1.md` Lead revisions 1–5): full `FCMP_WARNING_FLAGS` with `-Werror`;
   `FCDSP_NONBLOCKING` on every out-of-line definition of an annotated declaration; probe exit-code rules; ≤ 2 build
   directories at once, `-j6`, delete them after recording results.
2. **S2 lead revisions now in the base** (`docs/sprints/s2.md` Outcome): `BallisticsPolicy` and `Stage2Policy` REQUIRE
   `grDb(const State&)`; `oneMinusAlpha(tauMs, fs)` is in `core/Units.h`; every 20 ms gain transition uses a
   smoothstep-shaped `LinearRamp` (01 §5.1 note); `dsp.time` uses a 1 kHz square stimulus; FZ2 oversampler constants
   STD 4 / HQ 61 (01 §5.6), latency measured by LF phase / group delay, never impulse peak.
3. **F9.** `QuadKnee::solveFb` and `SmoothBranching::solveFb/commitFb` are declared but undefined (an FB Mode fails to
   link until you define them). Known skeleton gap: the ballistics float state stops short of a non-zero target
   (0.005 dB @ 200 ms / 48 kHz … 0.9 dB @ 5 s / 384 kHz) — fix it (e.g. carry the error / land on target) since Opto and
   Mu Modes depend on long releases. `dsp.registry` keeps writing `note("provisional", …)` every run. Clearing Clean's
   `provisional` makes its fidelity rows blocking: every `mode:clean` row must pass.
4. **F4.** Host ramps (bypass, listen, delta) use the smoothstep shape. `Oversampler::down()` may run in place, `up()`
   may not (except ECO); channels clamp to 1–4. The `tsan` preset is allowed in your worktree for the acceptance run
   (delete it afterwards); ~20 GB free.
5. **G4.** Lead revision: **`src/panel/HeadlessHost.cpp` is added to your OWNS** so you wire `HeadlessHost::writePng()`
   to SoftRaster (G3 left it returning false). The glyph additions move the atlas: expect candidates for
   `fg.font.probe`, `fg.shader.hash` (shader branch chain) and every `fg.gallery.*` section (incl. `primitives`); list
   each with its reason. Network access is allowed for ONE purpose: `pip install fonttools` into a throwaway venv under
   `$TMPDIR` to regenerate the font subset (02 §4.6); nothing else.
6. **[XV] for G4** uses the read-only worktree `/Users/seanfunk/audio/plugins/FCompressor/.claude/worktrees/ro-s3-g4`.
7. **G4 — lead-approved deviation (mid-sprint).** `include/funkgui/text/FontAtlasSdf.h` (frozen at FZ1) may change in
   exactly one hunk: the `kExtraChars` initializer expands `Glyphs.def` via `FUNKGUI_GLYPH(cp, name)`. Name, type,
   `kNumExtra` formula and every other line stay byte-identical.
8. **G4 — lead-approved deviation (mid-sprint).** G3's `canvas_parity`/`canvas_expansion` tests used U+2212/U+2026 as
   "missing glyph" fixtures, which G4 now bakes. Only the fixture codepoints change (U+2212 → U+2206, U+2026 → U+21BA,
   same UTF-8 length, absent from upstream JetBrains Mono); expected counts and assertion meaning are unchanged.
