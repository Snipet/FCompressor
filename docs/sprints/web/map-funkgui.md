# Web demo scout report: FunkGui without JUCE

Written by a read-only scout before Sprint A (ADR-93 design pass, 2026-10-01). Line numbers are as of main 3731e07.
Statements about WebAssembly behaviour were not built unless the report says a scratch test ran.

## Summary

FunkGui::core cannot build with Emscripten today with JUCE absent, but the gap is small and well bounded. It fails at three levels: (1) configure: FunkGui FATALs when the JUCE targets are missing unless FUNKGUI_HARNESS_ONLY (harness only), creates FunkGuiFonts with juce_add_binary_data and links three JUCE modules into FunkGuiCore; (2) compile: 6 of the 29 core translation units include JUCE directly (FontAtlasSdf.cpp, LineEdit.cpp, SoftRaster.cpp, UiPreferences.cpp, JuceParamPort.cpp, MenuLook.cpp) and 3 more get it through headers (ThemeCells.cpp and SegmentedSelector.cpp via UiPreferences.h, FontService.cpp via BundledFont.h -> FunkGuiFonts.h); (3) libc: CLocale.cpp's non-Apple branch calls strtol_l, which Emscripten 6.0.3's musl does not declare. The other 19 core TUs (Canvas, PrimList, Expand, Fingerprint, widgets, GestureController, a11y, live, TextFit, Env, Format, HeadlessHost, CaptureConfig) are plain C++20 with no platform conditionals. Panel, HostServices, Input, ParamPort, HeadlessHost.h and CaptureConfig.h are already JUCE-free headers (HostServices and LineEdit.h only forward-declare juce types). The one hard dependency is the font: the SDF atlas is baked at runtime by JUCE (typeface, HarfBuzz shaping, path fill into a juce::Image), and FunkGui's own distance transform is the only JUCE-free part. The atlas is a fixed 1024x512 R8 image plus 113 glyph records and 7 metrics, so it can be pre-baked on the host and embedded; macOS and Linux already bake identical metrics with different pixels, so embedding the macOS bake gives the browser the macOS layout bit for bit. A WebHost is the browser counterpart of EditorHost minus its surface lifecycle: a requestAnimationFrame clock with the 60/12 Hz cadence, tick/draw into a member Canvas, a sink for the expanded vertex stream, HTML5 pointer/wheel/key conversion to the plain input structs, CSS cursor, and the HostServices calls (most of which can keep their defaults). All of this is additive and belongs in one FunkGui MINOR (v0.12.0), golden impact none on macOS/Linux. I did not compile anything; the Emscripten claims come from reading its headers.

## Blockers and options

- **FunkGui has no JUCE-free core configuration: configure FATALs without JUCE targets, FunkGuiFonts comes from juce_add_binary_data, and FunkGuiCore links three JUCE modules.** (FunkGui cmake/FunkGuiDeps.cmake:169-173; cmake/FunkGuiTargets.cmake:273-281, :304-310; CMakeLists.txt:38-57)
  Options: (a) Recommended: new option FUNKGUI_WITH_JUCE (default ON). OFF skips the JUCE check, FunkGuiFonts, FunkGuiJuce, the juce link, tools and tests, forces FUNKGUI_WITH_PRESETS=OFF, drops src/juce/** and src/params/JuceParamPort.cpp from the glob, and defines FUNKGUI_HAS_JUCE=0 for the few guarded files. (b) Derive it from EMSCRIPTEN automatically (less explicit, cannot be exercised natively). (c) A separate FunkGui::corelite target with a hand-kept source list (breaks the globs-only rule). Option (a) can also be built natively on macOS, which gives a JUCE-free compile check without a browser.

  Options: (a) Recommended: commit a pre-baked atlas blob (the macOS bake, hash b744c79b9bb755d0: 512 KiB pixels + 113 glyph records + metrics; mostly zeros, compresses well), add FontAtlasSdf::adopt/loadBaked plus a serialiser, have FontService use it when JUCE is absent, add a tool mode that writes the blob and a macOS test that the blob equals the runtime bake bit for bit. ## Recommended approach

Do it as one FunkGui MINOR, v0.12.0 ("web / JUCE-free core"), golden impact none on macOS and Linux, then pin it from FCompressor.

1. Build seam. Add option FUNKGUI_WITH_JUCE (default ON) in CMakeLists.txt beside the existing options. When OFF: skip the JUCE presence/version check (FunkGuiDeps.cmake:169-189), FunkGuiFonts, FunkGuiJuce, _funkgui_link_juce, tools and tests; force presets off; exclude src/juce/** and src/params/JuceParamPort.cpp from the core glob; add FUNKGUI_HAS_JUCE=0/1 as an INTERFACE definition on FunkGuiCore. funkgui_configure_product stays required. Make it buildable natively as well as under Emscripten, so the JUCE-free core gets a fast compile check on macOS.

2. Font. Commit a pre-baked atlas (the macOS bake) and add to FontAtlasSdf an additive loader (for example adopt(const BakedAtlas&) or loadBaked(bytes)) and a serialiser. FontService::atlas() bakes with JUCE when present and adopts the blob otherwise; ok() stays true. Add a tool mode (FontProbe or AtlasDump) that writes the blob and a macOS test asserting blob == runtime bake (pixels, glyph table, metrics), so the blob cannot go stale when Glyphs.def or the subset changes. BundledFont.h and the TTF are not needed in the web build; the OFL licence text must still ship with the page.

3. Prefs. Keep UiPreferences' name and logical API; move storage behind a private backend. With JUCE: unchanged header surface and file format. Without JUCE: no JUCE include, an in-memory store, std::string filePath(), and an optional setBackend() the WebHost can point at localStorage.

4. Small fixes: __EMSCRIPTEN__ branch in CLocale.cpp; FUNKGUI_HAS_JUCE guards around printable(juce::String) in LineEdit.cpp and around writePng in SoftRaster.cpp.

5. WebHost, as a new FunkGui module (include/funkgui/web, src/web, target FunkGui::web, Emscripten only; rule: anything that includes emscripten headers lives there). It implements HostServices and owns a Canvas over FontService's atlas, like HeadlessHost and EditorHost. It must provide:
- Clock: requestAnimationFrame; dt from the timestamp clamped to 1 ms..100 ms; draw every frame while Panel::wantsFullRate() or after a nudge, else about 12 Hz; skip while the document is hidden; Panel::idle(now) at >= 10 Hz from a timer.
- Frame: follow UiPreferences::revision() for theme (and zoom if offered), tick(dt), fill FrameInfo (logical 960x640, dpi = canvas backing height / logical height = devicePixelRatio x zoom, theme ground and gamma), canvas begin / Panel::draw / end, submit expand()'s vertices with the atlas texture. Resize the backing store when devicePixelRatio changes. Handle WebGL context loss by recreating the program and texture (the analogue of EditorHost's re-attach).
- Input: pointer events to PointerEvent in logical px (CSS px divided by zoom), click count, popup for right or ctrl click (and suppress the browser context menu); pointer capture during a drag; wheel to WheelEvent in JUCE's units (pixel deltas x 0.5/256 with smooth = true, line deltas x 10/256 with smooth = false, sign flipped so up is positive); keydown to KeyEvent with the same key table as EditorHost and preventDefault when Panel::key returns true; cmd on Mac / ctrl elsewhere as mods.cmd. Nudge full rate and update the cursor after every event.
- Cursor: Panel::cursor() to CSS (default, ew-resize, ns-resize, pointer, crosshair).
- HostServices: nowSeconds from the page clock; nudgeFullRate; setUnboundedDrag via Pointer Lock (or a no-op relying on pointer capture); showParamMenu no-op (no host); beginBatch/endBatch forwarded to callbacks as EditorConfig does; themeIndex from UiPreferences; ownerComponent stays null; zoom calls either left at their defaults or mapped to the canvas CSS size.
- Teardown: Panel::closeGestures().
- Optional later: an ARIA mirror from Panel::accessibility / a11yAction; file drops delivered as paths in Emscripten's in-memory filesystem (the demo's audio-file drop can be handled by the page outside the Panel).

6. Parameters: no FunkGui change. The web build supplies its own ParamPort implementations (value store plus gesture callbacks) with native() returning nullptr, exactly as probe fakes do.

7. Leave FunkPresets and MenuLook out of the web build (FUNKGUI_WITH_PRESETS=OFF; src/juce excluded). FCompressor guards its menu/chooser/clipboard call sites for now; a host-neutral menu/clipboard seam on HostServices can be a later MINOR.

API surface that makes this a MINOR: the FUNKGUI_WITH_JUCE option, the FontAtlasSdf loader/serialiser, UiPreferences' JUCE-free shape and filePath()/setBackend, the new web headers and FunkGui::web target, and (only if chosen) the Harness wasm arch and the HostServices menu/clipboard additions. The CLocale branch and the two guards are not API.

## Effort notes

Nothing was compiled; "does not build today" rests on the CMake and include evidence plus Emscripten's headers, so the first JUCE-free compile may surface a few more small issues (warnings under -Werror, a missed transitive include). I believe the list is complete because the grep for JUCE and for platform conditionals over core was exhaustive.

Rough size, FunkGui side:
- JUCE-free core (option, glob filter, guards, CLocale branch): small; about 80 lines of CMake and 40 of C++. CMakeLists.txt and cmake/ are lead-only files.
- Pre-baked atlas: loader + serialiser + tool mode + test, about 200 lines, plus one committed blob (about 0.5 MiB raw). Needs a lead decision on the blob's format and location, since it is regenerated whenever golden impact is 'atlas'.
- UiPreferences backend split: about 150 lines; the risk is keeping the JUCE build byte-for-byte unchanged (fg.prefs.check and FCompressor's prefs probes cover it).
- WebHost: EditorHost.cpp is 1,061 lines, of which the surface lifecycle, fallback screen, zoom fitting and capture are not needed; HeadlessHost.cpp (355 lines) is the closer template. Expect 500-700 lines of C++ plus a small JS glue, and about 200 more for a WebGL2 sink if bgfx is not used.
- Two cards could run in parallel (JUCE-free core + atlas + prefs; WebHost), the second depending on the first only for linking.

Things I did not cover because they belong to other areas: whether FCompressor's Source/editor and ProcessorFacade compile without JUCE (I only listed the call sites that touch FunkGui's JUCE seams), the audio path (AudioWorklet, fcdsp), and the bgfx-versus-WebGL2 decision in depth.

Risks worth knowing early: browsers cannot distinguish a trackpad from a notched wheel reliably, so the smooth flag is a heuristic and widgets branch on it; wasm has no flush-to-zero control (relevant to Harness.h's ScopedFtz and to the DSP); the WebGL canvas should be created opaque because the sink writes alpha with straight alpha blending; the committed atlas makes the web build depend on a macOS bake, so a Glyphs.def or subset change needs the blob regenerated on a Mac (the proposed test catches a stale blob).
